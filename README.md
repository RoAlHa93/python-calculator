# My very first coding project (Classic Calculator)

Welcome to my very first coding project. What I'm trying to achieve with this project is to gain a baseline understanding and knowledge on programming. While many would disagree, I consider coding to be a thing of the past. I'm saying this with a certain degree of confidence since I have been working as a freelance translator and interpreter for the last 10 years. I can foresee that the classic translation work will sooner or later be a thing of the past. Translation deals with language, and large language models are specialized in just that: language. It shouldn't come as a surprise to anyone that LLMs also perform exceptionally in programming languages. Still, even in the age of vibecoding, I see the purpose behind a somewhat deeper understanding of the "behind the scenes" of programming, which is exactly what I want to achieve with this and the next upcoming projects I'm publishing here. Thank you!
